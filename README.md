# SDD AI Development Harness — Documentation Package

Este paquete contiene la documentación base para desarrollar el framework SDD (Specification-Driven Development).

## 📁 Estructura de Documentación

- `.docs/01-brief.md` — Visión, problema, propuesta de valor, alcance y principios.
- `.docs/02-technical-specification.md` — Arquitectura general, lifecycle del framework, integración de herramientas y calidad.
- `.docs/03-development-tasks.md` — Plan de implementación completo y ordenado por fases.
- `agents.md` — Definición de los agentes de IA, asignación de modelos por tarea y ciclo de orquestación.

## 🚚 Proyecto PoC (Shipping Logistics Gateway)

- `.docs/poc/README.md` — Visión general del PoC.
- `.docs/poc/technical-specification.md` — Especificación técnica del proyecto PoC.
- `.docs/poc/tasks.md` — Tareas específicas de implementación del PoC.

## 📌 Fuente de Verdad y Convenciones

- **Trazabilidad:** Estos documentos representan la especificación inicial. Cualquier evolución debe seguir el propio mecanismo SDD (changelog y decisiones registradas).
- **Diagramas:** Mermaid es el formato obligatorio. Lanshu puede utilizarse de forma complementaria.
- **Insumos Técnicos:** Las decisiones sobre versiones de dependencias, APIs de MCP y modelos deben validarse en la implementación.
